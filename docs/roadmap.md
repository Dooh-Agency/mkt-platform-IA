# Hoja de ruta — asistente de marketing visual

Actualización: 2026-11-11. Etapas orientativas; plazos, costos, participantes y umbrales se acuerdan tras las pruebas. El orden no sustituye las condiciones de seguridad para trabajar con datos reales.

| Etapa | Entrega | Dependencias y criterio para avanzar |
| --- | --- | --- |
| 0. Validar experiencia | Prototipo móvil y sesiones con 3–5 clientes; sugerencias y producción manual cuando haga falta. | Seleccionar clientes y recursos. Entienden el recorrido, reconocen valor y las dificultades tienen solución viable. |
| 1. Piloto visual seguro | Alta progresiva, identidad y fotos; una intención principal, plantillas, edición directa, guardado, vista previa, descarga y copia. | Acceso seguro, aislamiento, almacenamiento, soporte y recuperación antes de datos reales. Validar creación de piezas utilizables y voluntad de repetir. |
| 2. Sugerencias | Ideas por perfil, calendario revisado y recursos; aceptar, descartar y preferencias simples. | Datos suficientes y relevancia observada; no atribuir ideas editoriales a tendencias en tiempo real. |
| 3. Redes | Conexión priorizada, formatos viables, publicación y programación autorizadas. | Comprobar API, cuentas, permisos, revisión, costos, desconexión y fallos. |
| 4. Resultados | Interpretaciones simples basadas en métricas accesibles; evaluar fuentes de tendencias. | Conexión y datos suficientes; separar hechos de hipótesis y evitar promesas. |

La vista previa básica se prueba en la etapa 0 y se mejora por red; una sugerencia manual puede probarse desde el inicio. Las etapas pueden solaparse cuando sus dependencias lo permitan.

Detalle de piloto, decisiones, riesgos y diagnóstico en [producto/plan.md](producto/plan.md). Los controles de módulos se mantienen en [modulos.md](modulos.md).
