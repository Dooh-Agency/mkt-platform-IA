# ADR 0005: Prioridad del asistente de marketing visual

- **Estado:** Aceptada como dirección de producto; detalles sujetos a validación.
- **Fecha:** 2026-11-11
- **Autor(es):** Fernanda + Codex

## Contexto

El caso ancla de YouTube y el orden de módulos anterior no representan la experiencia prioritaria: pequeños negocios necesitan orientación, piezas visuales coherentes y edición intuitiva. El trabajo existente aporta bases técnicas pero no demuestra aún esa experiencia.

## Decisión

Priorizar la validación con clientes y un recorrido de publicación visual completo. El primer piloto funcional terminará en descarga y copia, con una vista previa orientativa; la conexión y publicación se agregan cuando haya factibilidad y autorización. Los datos reales requieren acceso seguro y aislamiento antes del piloto. El setup profesional es opcional y se cotiza aparte.

Este ADR modifica la prioridad de módulos del ADR 0004, no su principio de crecimiento modular. No selecciona todavía editor, proveedor, nicho definitivo ni precios.

## Consecuencias

Se anticipan diseño visual y prueba de usuario. YouTube, producción multimedia amplia, facturación completa y analítica avanzada dejan de ser condiciones previas. Deben medirse usabilidad, calidad, costo y soporte antes de ampliar alcance. La aprobación humana se distingue del control automático.
